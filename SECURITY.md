# Segurança

O Supaco lida com o acesso dos alunos ao SUAP, então vulnerabilidades são levadas a sério.

## Como reportar

**Não abra uma issue pública** para falhas de segurança. Use o
[relato privado de vulnerabilidades do GitHub](https://github.com/kellyson71/supaco-mobile/security/advisories/new)
ou envie um e-mail para o mantenedor pelo perfil do GitHub.

Inclua a versão do app, o modelo e a versão do Android e os passos para reproduzir.
Você recebe uma resposta em até 7 dias.

## Escopo

- Vazamento de senha ou token (logs, backup, armazenamento)
- Comunicação com servidores que não sejam `suap.ifrn.edu.br`
- Dados de um usuário visíveis para outro no mesmo aparelho

Problemas na própria API do SUAP devem ser reportados ao IFRN.
